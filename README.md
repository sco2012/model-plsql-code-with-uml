
# **Managing complex APIs with UML** and generating scaffold code from them


The key to managing a complex API (also called an *interface*) is to abstract away the code level detail into a model consisting of a set of UML class diagrams, using a proper repository based UML tools (not just a drawing tool).

A proper UML tool allows one to capture important characteristics, such as descriptions, parameters, descriptions of parameters, etc).  Also, a proper UML tools allows one to reuse classes across multiple diagrams.

Consider a scenario where one has an existing set of code, say, a complex API.  To get to grips with how it works, create a set of UML diagrams.
