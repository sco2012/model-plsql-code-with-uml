Returning ref_cursors, part 4

Method #3: SQL over database link 


      Wrapper that allows the results of fn4RefC() to be fetched using the form ::

          select
                *
          from
                fn4
          where
                xxschema."xxpub2".Setfn4(p1 => ??, p2 => ??) = 1 ;

      Note the use of the conjunctive function Setfn4()

      Allows the function to be executed over a database link ::

          select
                *
          from
                fn4@dblink
          where
                xxschema."xxpub2".Setfn4@(p1 => ??, p2 => ??) = 1

      Sets filtering criteria (by setting package global variables for the session). Always returns "1"

This form requires a view be created, named fn4. The creation of the view is handled by the init function, which is generated into the database package, and must be run once (the generated documentation explains exactly how to execute the init function).

Using this form, the data-set can be fetched across a database link, useful in instances where the consuming system is another Oracle database.
