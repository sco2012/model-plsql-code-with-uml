Returning ref_cursors, part 3

Method #2: SQL requires strongly-types data 

      Strong-type wrapper for fn4RefC() that allows the form ::

          select
                *
          from
                xxschema."xxpub2".fn4(
                      xxschema."xxpub2".fn4RefC(
                            p1 => ??, p2 => ??
                      )
                )
          ;

      Because this function returns a pipe-lined function it can not be called over a database link.

A ref-cursor can not be accessed directly with SQL, because a ref-cursor is not strongly-typed, and SQL requires strong-typing. This is resolved by providing a wrapping function (for the ref-cursor function) that does the type casting.
