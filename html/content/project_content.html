Modeling PL/SQL code using UML classes
Author smurgatroyd
Revision Number 131

UML classes provide a convenient way of modeling PL/SQL procedures, functions and packages.

In complex environments, packages might be designed by a senior developer or architect, using UML which can then serve as a specification for developers to develop the actual code.

Furthermore, using the extension demonstrated, much of the PL/SQL code can be generated, dramatically speeding up the development process. In this way, the designer can be concerned with how codes interface with one another, whilst the developer can be concerned with implementing the code logic. Such a separation of concerns is likely to lead to faster and cleaner development, with fewer errors.

The remainder of this document steps through using UML to generate PL/SQL code.
