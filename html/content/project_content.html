Modeling PL/SQL code using UML classes
Author smurgatroyd
Revision Number 131

Modeling PL/SQL with UML has the following advantages:

- It allows the modeller (usually a designer, senior developer, or architect) to visualise the code. This is especially important with complex code bases, where ensuring proper interfacing is critical.

- The modeller can give functional descriptions to every package, method and parameter, from which a specification can be generated.

- With a fully articulated specification, a code developer can proceed with coding without concerns of ambiguity.

- Modellers can focus on interfaces, whilst coders focus on code logic, achieving a separation of concerns and reducing the chance of errors.

- Scafolding-code can be generated from the model (ie. the structure of the code, with the methods and parameters correctly defined, with only core logic to be added). The generated code includes the descriptions from the model, making the code 'pre-documented'.

The remainder of this document steps through using UML to generate PL/SQL code.
