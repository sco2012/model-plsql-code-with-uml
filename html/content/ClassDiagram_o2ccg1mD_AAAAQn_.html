More complex models, part 3

Amongst the benefits, using UML class models to specify database code allows designers to create a visually compact representation of database code, which is especially helpful for large code bases.

It is a great way of creating specifications (or change specifications) for developers to implement. Also, a HTML form of documentation can be generated from the modeling tool (not shown here) suitable for non-database personnel who need to understand what the database code does without having to delve into the code.
