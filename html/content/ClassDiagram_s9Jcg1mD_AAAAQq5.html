Returning ref_cursors, part 2

Method #1: Iteratively processing a data-set 



        Returns a ref-cursor, which when executed returns records in the form ::

        COLUMN                        TYPE          DESCRIP
        ----------------------------  ------------  --------------------------------
        F1                            (Integer)
        F2                            (String)
        F3                            (String)

        Following is an example of calling this function in PL/SQL ::

        declare
          vRow xxschema."xxpub2".fn4Rec
          vCursor sys_refcursor;
        begin
          pCursor :=
                fn4RefC (
                    p1 => ??
                  , p2 => ??
                );
          loop
              fetch pCursor into vRow;
              exit when pCursor%notfound;
              -- Do useful stuff
          end loop;
          close pCursor;
        end;

The generated code stub shows PL/SQL to process records one at a time. Languages such as Java, Python, Go and most others, have constructs to iterate over data returned from ref-cursors. PL/SQL requires strongly-typed data, which is handled by the vRow variable, which is a record-type corresponding, to the model:

type fn4Rec is record (F1 number, F2 varchar2(32), F3 varchar2(1024));
